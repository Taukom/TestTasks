===============================
Тест-кейсы для оплаты банковской картой
===============================

ID: 1
Название: Успешная оплата заказа банковской картой
Предусловия: Пользователь авторизован, корзина содержит товары, валидные данные карты готовы
Шаги:
  1. Перейти на страницу корзины
  2. Нажать «Оплатить»
  3. Ввести корректные данные карты
  4. Подтвердить оплату
  5. Пройти 3-D Secure, если редирект произошёл
Ожидаемый результат:
  - Оплата проходит успешно
  - Статус заказа обновлён на «Оплачен»
  - Пользователь видит сообщение об успешной оплате
  - На email отправлен чек

--------------------------------------------------

ID: 2
Название: Оплата отклонена банком
Предусловия: Пользователь авторизован, корзина с товарами, карта будет отклонена банком
Шаги:
  1. Перейти на страницу корзины
  2. Нажать «Оплатить»
  3. Ввести данные карты, которая будет отклонена банком
  4. Подтвердить оплату
Ожидаемый результат:
  - Платёж отклонён
  - Статус заказа остаётся «Не оплачен»
  - Пользователь видит сообщение «Оплата отклонена банком»
  - Чек не отправляется

--------------------------------------------------

ID: 3
Название: Оплата с минимальной и максимальной суммой
Предусловия: Пользователь авторизован, корзина с суммой в пределах граничных значений
Шаги:
  1. Перейти на страницу корзины
  2. Ввести минимальную допустимую сумму и оплатить
  3. Проверить результат
  4. Повторить с максимальной допустимой суммой
Ожидаемый результат:
  - Оплата проходит успешно для обеих сумм
  - Статус заказа обновляется корректно
  - Пользователь видит сообщение об успешной оплате
  - На email отправлен чек

--------------------------------------------------

ID: 4
Название: Валидация некорректных данных карты
Предусловия: Пользователь авторизован, корзина с товарами
Шаги:
  1. Перейти на страницу оплаты
  2. Ввести некорректный номер карты (меньше/больше 16 цифр)
  3. Ввести некорректный CVV или дату истёкшей карты
  4. Нажать «Оплатить»
Ожидаемый результат:
  - Отображается ошибка валидации (например: «Неверный номер карты»)
  - Данные не отправляются в платежный шлюз

-------------------------------------------------

ID: 5
Название: Ошибка платёжного сервиса
Предусловия: Пользователь авторизован, корзина с товарами, имитация сбоя шлюза
Шаги:
  1. Перейти на страницу оплаты
  2. Ввести корректные данные карты
  3. Подтвердить оплату
  4. Сымитировать сбой платежного шлюза
Ожидаемый результат:
  - Отображается сообщение «Ошибка платёжного сервиса»
  - Статус заказа остаётся «Не оплачен»
  - Чек не отправляется
